# Spotter 1.2.0 release verification

Status: annotated `v1.2.0` pushed and container images published successfully.
The tag points to `7801e5419e42873f2f7206b0485b774de14f266f`. The separate GitHub
release-notes entry remains pending authenticated GitHub access. No production
data was accessed or changed during verification.

## Passed locally

- Clean dependency install from the lockfile. The Mac's certificate chain
  prevented downloading native-module headers; using its installed Node headers
  with `npm_config_nodedir=/Users/melvinmicallef/.nvm/versions/node/v20.20.2 npm ci`
  succeeded without disabling TLS verification.
- `npm run check`: formatting, lint, TypeScript, 85 unit/integration tests,
  9 release-metadata tests, and production builds.
- All 13 Playwright browser tests with installed Chrome, including mobile and
  desktop layouts, both themes, offline recovery, duplicate prevention, and
  confirmation dialogs.
- `docker build --build-arg APP_VERSION=1.2.0 --tag spotter:release-candidate .`.
- Disposable mounted-volume checks: upgrade a version-one SQLite database,
  preserve primary targets, templates and recorded workout values, verify
  `/api/health`, `/api/version`, PWA routes and manifest, upload a GIF, replace
  the container and verify retained media, then back up the stopped volume and
  restore it into a separate directory. Both migration records, removal of the
  role column, and `foreign_key_check` were verified.

## Agreed release decisions

- Secondary muscle links are deleted by the owner-approved 1.2.0 upgrade;
  preserve primary links, workout history, templates, and pending device sync.
  Back up `/data`, keep browser site data, and restore a pre-upgrade backup to
  roll back. See the recorded decision in [architecture](../architecture.md).
- The owner explicitly chose to leave dependency versions unchanged despite
  the existing high-severity Zod advisory reported by `npm audit --omit=dev`.
  The advisory and deployment limitations are disclosed in the changelog.
